# 📝 My Tasks - 스마트 반응형 할 일 관리 앱

> 서버나 복잡한 설정 없이 브라우저에서 즉시 실행되며, 데스크톱과 모바일 모두에 최적화된 올인원 할 일(Todo List) 관리 웹 애플리케이션입니다.

---

## 🌟 주요 특징 및 핵심 기능

### 1. 📊 한눈에 보는 진행률 대시보드
- **전체 달성률 게이지**: 완료된 태스크 비율을 퍼센티지와 시각적 프로그레스 바로 실시간 표시합니다.
- **카테고리별 미니 통계**: 업무, 개인, 공부 각 카테고리별 완료 현황(`완료/전체`)을 즉시 파악할 수 있습니다.
- **헤더 알림 배지**: 미완료된 `남은 일 N개`와 당일 생성된 `오늘 등록 N개`를 자동으로 집계합니다.

### 2. 🗂️ 3가지 카테고리 태스크 분류
- **업무 (Work)**: 파란색 테마 (`#4A90E2`)
- **개인 (Personal)**: 초록색 테마 (`#27AE60`)
- **공부 (Study)**: 보라색 테마 (`#8E44AD`)
- 상단 탭을 통해 카테고리별로 원하는 할 일만 즉시 필터링하여 조회할 수 있습니다.

### 3. 🌙 다크 모드 & 라이트 모드 지원
- 우측 상단 토글 버튼(`🌙` / `☀️`)을 통해 손쉽게 테마를 변경할 수 있습니다.
- 눈의 피로도를 낮추는 다크 테마(배경: `#1A1A1A`, 카드: `#2D2D2D`, 텍스트: `#E0E0E0`)가 적용됩니다.
- 사용자의 테마 설정은 `localStorage`에 안전하게 보존되며, OS 설정에 맞추어 자동 초기화됩니다.

### 4. ⚡ 고도화된 사용자 경험 (UX)
- **인라인 더블클릭 수정**: 할 일 텍스트를 **더블클릭**하면 인라인 편집 모드로 전환되어 내용 및 카테고리를 바로 수정할 수 있습니다.
- **실시간 즉시 검색**: 검색창에 키워드를 입력하는 순간 실시간으로 리스트가 필터링됩니다.
- **완료 항목 일괄 정리**: 한 번의 클릭으로 완료된 태스크들을 한 번에 안전하게 삭제(`confirm` 확인 다이얼로그 제공)할 수 있습니다.
- **생성 시간 표시**: "방금 전", "5분 전", "2시간 전" 등 읽기 쉬운 상대 시간으로 표기됩니다.
- **부드러운 인터랙션**: 프로그레스 바 게이지 전환, 항목 추가 페이드인, 삭제 페이드아웃 효과가 기본 적용되어 있습니다.

### 5. 🖥️ 반응형 2컬럼 데스크톱 레이아웃
- **데스크톱 화면**: 좌측 사이드바(대시보드 통계, 등록 폼, 단축키 팁)와 우측 메인 패널(필터/검색 툴바, 할 일 목록)의 2열 그리드로 넓은 화면을 능률적으로 활용합니다.
- **태블릿 및 모바일**: 화면 너비가 좁아지면 자연스럽게 1열 스택 구조로 전환되어 모바일 환경에서도 가로 스크롤 없이 편리하게 사용 가능합니다.

## ⌨️ 생산성을 높여주는 키보드 단축키

| 단축키 | 동작 |
| :--- | :--- |
| <kbd>Alt</kbd> + <kbd>N</kbd> | 새 할 일 입력창으로 즉시 포커스 이동 |
| <kbd>Alt</kbd> + <kbd>1</kbd> | **전체** 할 일 보기 |
| <kbd>Alt</kbd> + <kbd>2</kbd> | **업무** 카테고리 필터 |
| <kbd>Alt</kbd> + <kbd>3</kbd> | **개인** 카테고리 필터 |
| <kbd>Alt</kbd> + <kbd>4</kbd> | **공부** 카테고리 필터 |
| <kbd>더블클릭</kbd> | 해당 할 일 인라인 편집 모드 진입 |
| <kbd>Enter</kbd> | 할 일 등록 / 인라인 수정 내용 저장 |
| <kbd>ESC</kbd> | 인라인 수정 취소 및 복원 |

## 🚀 시작하기 (설치 불필요)

외부 패키지 설치나 로컬 웹서버 구동 없이 파일 자체로 바로 실행할 수 있습니다.

1. 프로젝트 디렉터리의 [`index.html`](file:///Users/taekr/taekr/code/ibk_digi_assoc/AI_NoCode/Lab4/index.html) 파일을 Chrome, Edge, Safari 등 웹 브라우저에서 직접 더블클릭하여 엽니다.
2. 입력창에 할 일을 입력하고 <kbd>Enter</kbd> 키를 누르면 바로 태스크 관리가 시작됩니다.
3. 브라우저를 닫거나 새로고침해도 `localStorage`를 통해 입력한 모든 데이터와 테마 설정이 안전하게 유지됩니다.
